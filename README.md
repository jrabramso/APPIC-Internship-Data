# APPIC-Internship-Data
Data on APPIC internship sites scraped from the web on September 10, 2026

This file includes data on all APPIC internship sites in the US scraped from an APPIC directory search (URL below) on September 10, 2026. For data in which multiple years are available, only data from 2025-2026 and 2026-2027 was included. Variables not present in most entries are not included. For speed and ease, code to scrape data was written by ChatGPT based on a back and forth conversation. See appic_data_all.csv for the data. See CodeToScrapeSite.R for code.
